# 用户使用手册（6.4.4）

> 面向**最终用户**（不是开发者）。开发者请看 `README.md` 与 `docs/系统架构设计.md`。

---

## 一、这是什么 / 不是什么

本系统帮你做两件事：

1. **判断自己偏向九种体质中的哪一种**（依据 GB/T 46939—2025 的等级计分法，确定性算法）；
2. **给出日常食疗的药材与药膳方向**（只推荐国家卫健委 106 种药食同源目录内的品种）。

**它不做这些事**——请务必了解：

- ❌ **不做疾病诊断**。任何"你得了什么病""这个方子治你的病"的说法都不会出现，
  系统也会主动过滤这类表述。
- ❌ **不替代医生**。身体持续不适应当前往医疗机构就诊。
- ❌ **不推荐处方药**。像附子、朱砂这类药材，在药材库里**查得到**（学知识用），
  但永远不会出现在给你的推荐方案里。

## 二、五分钟走一遍

### 步骤 1：打开与知情确认

手机浏览器访问系统首页。**首次进入会弹出《免责声明》，必须点"我已阅读并同意"才能继续**。
这一步不能跳过——它是安全设计的一部分，不是形式主义。

### 步骤 2：做体质测试

首页点「体质测试」→ 先写一句你的主要感受（比如"冬天怕冷、手脚冰凉、容易累"），
然后回答 27 道问卷题。每题按"没有 / 很少 / 有时 / 经常 / 总是"选。

> 小提示：主诉写得越具体越好。「怕冷手脚冰凉」比「不舒服」能得到更准的推荐。

### 步骤 3：看 AI 追问（可能有）

如果你回答的题太少、信息不足以判断，系统会**追问 1–2 个具体问题**，
最多追问 2 轮。这是刻意的：信息不够时不硬给结论。

回答后系统继续分析。

### 步骤 4：看结果

结果页包含：

| 区块 | 说明 |
| --- | --- |
| 主体质 / 兼夹体质 | 例如「阳虚质」，兼夹「气虚质」 |
| 九维雷达图 | 九种体质各自的转化分（≥40 判定"是"，30–40 判定"倾向是"） |
| 推理依据 | 为什么判成这个体质，可逐条核对 |
| **知识依据** | 结论依据了知识库里的哪几条内容，标 `[1] [2]`，可点击跳转查看原文出处 |
| 推荐药材 | 每味都标明用量与禁忌，**全部 ∈ 106 药食同源目录** |
| 安全层拦截记录 | 哪些品种被系统拒绝或替换了，透明可查 |
| 多智能体执行轨迹 | 这次分析实际跑了哪些节点 |

### 步骤 5：看药膳方案

点「查看药膳方案」，得到可操作的食疗建议。药膳卡片可以**保存为图片**分享。

### 步骤 6：回顾历史

「我的」页面可以看问诊历史与**体质变化趋势图**，也可以打开任意一条记录看完整对话过程。

## 三、怎么看懂结果

### 3.1 转化分是什么意思

```
转化分 =（原始分 − 条目数）÷（条目数 × 4）× 100
```

- **≥ 40 分**：判定为「是」这种体质
- **30–40 分**：判定为「倾向是」
- **< 30 分**：判定为「不是」

分数是**算出来的**，不是 AI 猜的。同一份问卷无论测多少次，结果完全一致。

### 3.2 九种体质速查

| 体质 | 常见表现 |
| --- | --- |
| 平和质 | 精力充沛、睡眠良好、适应力强 |
| 气虚质 | 容易疲乏、气短、说话没力气、易出汗 |
| 阳虚质 | 怕冷、手脚冰凉、喜热饮、精神不振 |
| 阴虚质 | 手足心热、口干咽燥、失眠多梦 |
| 痰湿质 | 身体沉重、腹部松软、痰多、舌苔厚腻 |
| 湿热质 | 面部油腻、易长痘、口苦口臭、大便黏滞 |
| 血瘀质 | 肤色晦暗、容易出现淤青、唇色偏暗 |
| 气郁质 | 情绪低落、胸闷、易紧张焦虑 |
| 特禀质 | 过敏体质、易起荨麻疹、对季节变化敏感 |

> 很多人是**兼夹体质**（比如阳虚兼气虚），这是正常的。

### 3.3 「知识依据」怎么用

结果页每段结论后面可能有 `[1]`、`[2]` 这样的标记。点它就会跳到底部的对应条目，
告诉你这句话依据的是知识库里的哪一条（含来源文件与切片编号）。

**这是判断回答可信度的抓手**：如果一段结论后面没有任何 `[n]` 标记，
说明它没有落在知识库内容上，请谨慎对待。

## 四、常见问题

**Q：为什么我说了"胸痛"，系统不给我分析？**
A：这是**急症拦截**。胸痛、呼吸困难、咯血、晕厥这类症状需要立即就医，
系统会直接终止问诊并提示拨打 120。这不是 bug，是安全设计。

**Q：为什么推荐里没有某某名贵药材？**
A：药膳属于普通食品，法定只能使用 106 种药食同源目录内的品种。
不在目录里的品种（哪怕很常见）一律不进方案。被拦下的品种会在
「安全层拦截记录」里列出来，并给出替换建议。

**Q：为什么有时 AI 会先问我问题再给结论？**
A：你提供的信息不足以判断体质时，系统会追问，最多 2 轮。
宁可多问一句，也不硬给一个不靠谱的结论。

**Q：结果页面一直在转圈怎么办？**
A：系统会在 45 秒没有收到任何数据时自动判定超时并提示你重试（6.2.4）。
网络波动导致的早期连接失败会自动重试一次。若持续失败，请检查网络后重新测试。

**Q：我是孕妇 / 哺乳期 / 儿童，能用吗？**
A：可以，但请务必在测试时勾选对应的人群标记。
系统会据此剔除不适宜的品种（比如孕妇剔除山楂、当归等）。

**Q：两次测的结果不一样？**
A：如果问卷答案完全一样，结果**必然完全一样**（确定性算法）。
如果不一样，说明答案变了，或者主诉描述不同——主诉会影响推荐的排序。

## 五、数据来源与局限（请如实看待）

| 数据 | 来源 | 状态 |
| --- | --- | --- |
| 药材百科（604 味） | 开源参考数据集 `tcm_828_herbs.json` 去重后 | 仅供学习参考，须与《中国药典》核对 |
| 药食同源目录（106 种） | 国家卫健委《既是食品又是中药材的物质目录》 | 性味/归经/功效/用量/禁忌为初稿，**尚未逐条人工核验** |
| 体质判定标准 | GB/T 46939—2025 | 标准原文未获取，问卷题面按九种体质通行表述编写 |
| 知识库 | 734 片切片（药材 604 / 药食同源 106 / 体质 9 / 症状 11 / 安全规则 4） | 已建索引，检索自检 7/7 |

**结论只作为日常食疗的方向参考**，不构成任何医疗建议。
