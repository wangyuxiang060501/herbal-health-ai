| 建议人工复核的条目 | 198 |

## 一、合并策略（确定性，可复现）

| 字段 | 规则 |
|---|---|
| `category` / `meridian` / `dosage` | 取出现次数最多者；并列时取首次出现 |
| `effect` | 取最长值（信息更完整） |
| `component` | 各来源成分清单取并集，按首次出现顺序去重 |
| `merged_from` / `source_indexes` | 保留来源记录数与原索引，便于溯源 |
| `conflicts` | 记录发生分歧的字段名，供人工复核 |
